 # Digital Health System

A web-based Digital Health System designed to manage and organize basic health-related information of migrant workers and make it easier for healthcare professionals to access relevant information.

## 📌 Project Overview

The Digital Health System is a web-based platform designed to support the digital management of healthcare information for migrant workers.

The system aims to make health-related information easier to organize and access, helping healthcare professionals obtain relevant information more efficiently when providing treatment.

The current project is developed using HTML, CSS, and JavaScript and can run directly in a web browser.

## 🎯 Objectives

- Provide a simple digital healthcare interface.
- Organize health-related information of migrant workers.
- Make healthcare information easier to access.
- Provide a user-friendly and responsive interface.
- Reduce dependency on manual health records.
- Support faster access to relevant information during treatment.

## ✨ Features

- 🏥 Digital health information system
- 👤 Migrant worker health information
- 📋 Organized health-related information
- 🔍 Easy navigation
- 📱 Responsive web interface
- ⚡ Interactive JavaScript functionality
- 🎨 Clean and modern user interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive functionality
